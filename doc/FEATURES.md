# 收纳助手功能介绍

收纳助手是面向竖屏 Android 手机的家庭物品库存应用。物品、位置、数量和操作历史存储在手机本地；位置名称可以自由输入，无需先创建抽屉清单。支持 Android 13 及以上版本。

## 记录与查找

- **语音记录**：按住说话，松手后由用户配置的 ASR 服务识别文字，再由主线路 LLM 判断放入、取出、查询、纠错或删除意图。一次话语可包含多件物品。录音时上滑松手可取消。
- **识别反馈与核对**：首页显示录音、识别和处理进度。待核对的行可直接编辑位置、物品和数量；没有有效 LLM 结果时不会写库存。语音已有文稿但理解失败时可用该文稿重试，无需重新录音。
- **结果保留**：最近的核对卡和查询结果卡可在重启后恢复；若库存变化使查询结果过期，卡片会提示重新查询。
- **无网查找**：搜索页可按关键词或类别浏览物品，并查看各位置的数量。详情页可编辑名称、别名、类别、有效期和提醒阈值。搜索和已有本地数据无需语音服务。

## 历史、提醒与备份

- **历史与撤销**：保留取放操作及相关识别证据。撤销会标记原操作；同一物品及位置的后续依赖操作会阻止不安全撤销。已删除物品可从回收站恢复。
- **提醒**：展示临期和冷门物品；可单独为物品开启零库存或安全库存提醒。补货提醒默认关闭，判断依据是该物品所有在架位置的合计数量。提供每天 20:00 汇总和稍后提醒，实际送达还取决于 Android 通知权限及系统后台限制。
- **备份与恢复**：本地导出 JSON v4，并可导入 v2/v3/v4；可选坚果云 WebDAV 或用户自建备份服务，支持手动和定时备份、列表、下载与恢复。恢复会替换当前库存，操作前应保存原数据。
- **存储与排查**：配置页可查看应用占用，导出或清除语音录音与诊断记录。库存备份不包含这些记录。

## 账号和数据边界

安装后在「配置 → 语音与 AI」填写自己的 ASR 与主线路 LLM 地址、模型和 API Key；备用 LLM 完全可选，主线路失败时才尝试。可分别测试连接，测试请求可能产生服务费用。配置由 Android Keystore 保护并保存在本机，APK 不内置个人 API Key。

语音发送到使用者配置的 ASR 服务，识别文稿和用于理解意图的库存上下文发送到配置的 LLM 服务。启用云备份后，完整备份文件发送到使用者选定的云端；该 JSON 文件是明文，云端管理员可能读取。未配置网络服务时仍可查看和维护已有的本地数据，云端语音识别无法工作。

自建备份服务的接口见[API 文档](API.md)，配置步骤见[开源与配置说明](OPEN_SOURCE.md)。
